# Runex

> Runex is an easy cloud deployment platform for developers.

Also known as: Runex Cloud
Website: https://runex.cloud

## What Runex does

- Deploy applications from GitHub (GitHub App) or Docker (Dockerfile)
- Run workloads in isolated containers with resource controls
- Provide HTTPS URLs on *.runex.cloud
- Support custom domains via CNAME to cname.runex.cloud
- Inject configuration through environment variables
