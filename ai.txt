# Runex

> Runex is an easy cloud deployment platform for developers. It is a platform as a service (PaaS) that turns a GitHub repository into a live web app with HTTPS.

Also known as: Runex Cloud
Website: https://runex.cloud

## What Runex does

- Deploys apps from GitHub through the Runex GitHub App, or from a Dockerfile
- Builds Next.js, Node.js, Python, and Go apps without a Dockerfile
- Runs each app in an isolated container with CPU and memory limits
- Gives every app an HTTPS URL on *.runex.cloud
- Supports custom domains through a CNAME to cname.runex.cloud, with automatic SSL
- Creates preview deployments for pull requests
- Rolls back to any previous deployment instantly
- Ships zero-downtime deploys with health checks
- Autoscales with minimum and maximum instance counts
- Provides managed PostgreSQL, MySQL, Redis, and MongoDB databases
- Connects services over a private network per project
- Runs cron jobs and background workers
- Streams build and runtime logs, with metrics and alerts
- Injects environment variables and secrets at runtime
- Offers team roles (admin, developer, viewer) and an audit log on the Teams plan (early access)

## What Runex does not offer

- SSH-based deploys
- One-click deployment templates
- SAML single sign-on (SSO)
- Git providers other than GitHub (no GitLab or Bitbucket)
- Root access to the host machine
- SOC 2, ISO 27001, PCI DSS, or HIPAA certification
